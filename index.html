About & manual guide

  
Version 2.0 · Independent companion, not Primera software. No connection to Freddie, no automatic dispensing and no cloud storage. FreddieView on Windows remains the machine controller.

  
What's new in 2.0
    
    
  • Reads FreddieView's log (C:\ProgramData\PTI\FreddieVision\FreddieVision.log): calibration readings, setting changes, cookies iced, icing used, and machine or camera faults, per day.
    • 
    
  • Edits FreddieView's settings (Persistence\visionsettingsWorkingCopy.json): flood and outline pressure, relative icing amount and distance from edge. Only those numbers change; the rest of the file stays byte-for-byte identical. Every save first writes a backup to FreddieVision\CalibratorBackups (and keeps one in this browser), and Undo last save puts it back.
    • 
    
  • Pressure steps from your own readings. FreddieView reports "too thin" when the reading is above its pass window (default 0.19–0.29) and tells you to decrease pressure, and "too thick" below it. The companion brackets the pressure between the highest that read too thick and the lowest that read too thin, and suggests the midpoint.
    • 
    
  • Reliability check. If readings contradict each other (for example, too thick at a higher pressure than one that read too thin, or readings over 1"), more calibration won't converge. It then recommends trial & error.
    • 
    
  • Trial & error mode skips calibration and changes one setting per cookie based on what you see. FreddieView lets you start a job without a passing calibration. Note that it still logs a "Flood Width … @Pressure …" from the last calibration at each job and may use it to plan flood spacing. If spiral spacing looks wrong, run one calibration, accept the result and continue.
    • 
  

  
Run records are saved in this browser for this page's address. Export a JSON backup regularly; import it to restore or transfer sessions.

The bracketing midpoint, ±5 pressure / ±5 % amount / +0.02 in edge steps, the reliability rules and one-variable-at-a-time sequencing are companion heuristics, not manufacturer prescriptions. Save limits (pressure 10–100, amount 30–200 %, edge 0–0.5 in) are guardrails, not approved operating limits.

  
Do not bypass interlocks. Disconnect power before nozzle changes or maintenance. Editing FreddieView's files is unsupported by Primera: keep the backups, and use Undo last save or FreddieView's Restore Defaults if anything looks wrong. Never use this app to assess food safety.
