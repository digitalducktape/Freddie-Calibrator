About & manual guide

Version 1.0 · Independent companion, not Primera software. No connection to Freddie, no automatic dispensing and no cloud storage. FreddieView on Windows remains the machine controller.

Open this HTML file in a modern browser. Run records are saved locally in this browser for this file location. Moving the file, changing browsers, private browsing or clearing browser data can lose access to history. Export a JSON backup regularly; import it to restore or transfer your sessions. Storage errors are shown explicitly.

Manual references
  • User’s Manual, edition 1.1, 012826: §3 p.28 — spatula settle test, 15–20 seconds; p.30 — dry tube/plunger; p.31 — prime after more than 3 hours idle.
  • §4B1 p.38 — thin: outline 30–40, flood 40–70; thick: outline 40–70, flood 70–100. Advanced settings only when directed by technical support.
  • §4B4 p.43 — calibrate each new batch; calibration cookie at least 2 inches wide; very thick icing may not be compensable.
  • §4C pp.44–45 and §6B p.72 — test one cookie, start edge 0.10 in (about 2.5 mm), amount 100%; adjust amount for more or less icing.
  • §4D p.46 — smaller nozzle for thinner icing. Available sizes: 1.2, 1.4, 1.6 mm. The text calls 1.4 “largest” but also lists 1.6; this app uses actual numerical sizes.
  • §5 pp.47–50 — disconnect power before maintenance; clean and fully dry valve/block/nozzle; check clear nozzle.
  • §4A p.36, §6A7 pp.69–70, §6C pp.76–77 — calibration failures may be camera/light related; inspect exposure and cookie preview.
  • §7B p.80 — missing icing throughout: increase relative amount by 5%; missing spirals: icing may be too dry/thick and need a new batch.
  • Quick Start 511510-061225: pp.14–15 (dryness/priming), p.17 (lighting), p.22 (pressure ranges), p.25 (edge/amount), p.27 (dry block/valve).

The pressure midpoints (35/55, 55/85), +0.02 in edge trials, −5 percentage point amount trials, and one-variable-at-a-time sequencing are companion heuristics, not manufacturer prescriptions. Numeric input limits are journal guardrails, not approved machine operating limits. Confirm FreddieView permits any setting before using it.

Do not bypass interlocks or adjust advanced settings without technical support. Disconnect power before nozzle changes or maintenance and use the full manual removal/reinstallation procedure. Use a fresh, uniced calibration cookie; do not assume “too thin” proves your recipe is wrong. Never use this app to assess food safety.
